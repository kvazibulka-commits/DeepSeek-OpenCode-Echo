# Летопись ЭХО · Android

## Следующий шаг

Собрать APK через CI, поставить на телефон и проверить живой эфир в домашней сети:
сонар, перехват Яндекс Музыки, отклик с ПК. После этого — виджет «Сейчас играет».

## 2026-11-16 · 0.1.0 · Новый клиент с нуля

**Сделано**

- Новый Android-проект: Kotlin 2.0.21, Compose BOM 2024.06.00, AGP 8.5.2, minSdk 26,
  compileSdk 34 (набор версий выбран под SDK 34 без предупреждений AAR-метаданных).
- Чистая структура: `domain` / `data` / `ui`, ручной DI, единый `EchoRepository`.
- Четыре экрана канона + настройки, нижняя навигация, тёмная тема из токенов ЭХО.
- Сонар на Compose Canvas: кольца, луч, сигналы, призраки, тайники, тепло, Лагранж,
  рассвет; тап по сигналу открывает паспорт.
- Дека: винил, архетип, присутствие, ручная трансляция, доступ к уведомлениям.
- Тайники: радиус 250/500/1000, список, звуковой замок, B2B-капсулы, шторка создания.
- Отзвуки: история откликов и летопись вечера.
- Сеть: OkHttp + kotlinx.serialization, DataStore для настроек, стабильный deviceId,
  нормализация адреса (LAN → http, туннель → https), Mutex на все запросы.
- Опрос с жизненным циклом: старт на ON_START, пауза на ON_STOP, 2.5 с / 7 с.
- Медиа-служба: MediaController.Callback + опрос 2.5 с, allowlist пакетов, фильтр мусора.
- Тесты: EchoUrlTest, TrackTextTest, EchoMappingTest.
- CI: `.github/workflows/android.yml`, debug APK в артефактах, общий debug-keystore.

**Проверки**

- `assembleDebug` — успешно, `ru.echo.radar` 0.1.0 (versionCode 1), minSdk 26, targetSdk 34,
  APK ≈ 10.7 МБ, launchable activity на месте.
- `testDebugUnitTest` — 17 тестов, все зелёные (URL 6, треки 7, парсинг состояния 4).
- `aapt2 dump badging` — пакет, SDK и activity корректны.

**Проблемы**

- Локального JDK/SDK в системе не было: тулчейн скачан во временную папку,
  в проект не входит.
- Кириллица в пути проекта: для сборки добавлен `android.overridePathCheck=true`,
  для тестов пришлось прогнать проект из `C:\Users\Public\echo-build` — иначе
  Gradle-воркер не стартует. В CI (Ubuntu) этой проблемы нет.
- Сервер не имеет `/api/health` и `/api/playlist`: проверка связи идёт через
  `/api/state`, плейлист строится из летописи.
- Репозиторий на GitHub ещё не создан: нужен токен с правом `repo`.
