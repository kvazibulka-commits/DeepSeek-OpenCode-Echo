## Выбранное направление

Гибрид **A + B**:

- база — «Ночной винил»: токены, спокойный фон, сигнальный циан только на живом;
- из Expressive — крупные заголовки и метрики, плавающая пилюльная навигация,
  сегментированный переключатель, пилюльные кнопки;
- из журнала — редакционные строки сигналов: номер, архетип, трек антиквой,
  резонанс моноширинным справа.

Реализовано в версии 0.2.0.

## Как проверить макет

```bat
start docs\design\variants-0.2.html
```

Или отрендерить Compose-превью:

```bat
android preview list :app
android preview render :app --fqn ru.echo.radar.ui.preview.AirPreview --output docs\design\previews
```

Ограничение: если `%USERPROFILE%` содержит кириллицу, Android CLI может не найти
кэш `~/.android/cache/preview`. В этом случае рендерять из ASCII-профиля или в CI.

## Правила

- Сначала три HTML-варианта, потом выбор, только затем Compose.
- Не смешивать больше двух акцентных цветов в одном блоке.
- Русский текст проверять в худшем случае: длинный исполнитель, три строки послания.
- Тап-таргет не меньше 44 dp, контраст тела — не ниже 4.5:1.
- Анимации интерфейса — до 300 мс; сонар и винил — медленные и непрерывные.
