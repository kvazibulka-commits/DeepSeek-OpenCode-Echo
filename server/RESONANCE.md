# Резонанс ЭХО 2.0

Документ описывает точный алгоритм, который считает `compatibilityPercent`
для каждого сигнала на сонаре. Клиент ничего не пересчитывает — сервер отдаёт
готовое число и объяснение (`resonanceStory`).

## 1. Вход

Два трека: мой и соседский.

| Поле | Откуда |
|---|---|
| `artist` | метаданные плеера / пульт |
| `title` | метаданные плеера |
| `album` | метаданные плеера / пульт |
| `genre` | плеер → Яндекс → каталог ЭХО → «не указан» (см. `ARCHETYPES.md`) |
| `bpm`, `camelot`, `energy`, `valence` | выводятся из жанра + хеша трека |

Никаких внешних API: одинаковый трек всегда даёт одинаковый результат.

## 2. Нормализация

Для всех строк:

1. Unicode NFKC, нижний регистр.
2. Удаляются скобки и их содержимое: `(Deluxe)`, `[Remastered]`, `(feat. X)`.
3. Отрезается `feat. / ft. / при уч. / при участии`.
4. Пунктуация заменяется пробелами, пробелы схлопываются.
5. Для альбомов дополнительно удаляются `deluxe`, `remastered`, `edition`, `ep`, `single`, `version`.

Коллаборации артистов делятся по `, & / and x vs × +`.
Для каждого артиста берётся лучшее совпадение по частям.

## 3. Сходство строк

`text_similarity(a, b)`:

- точное совпадение → **1.0**;
- одна строка содержит другую при длине ≥ 4 → **0.85**;
- иначе `max(Jaccard по словам, Dice по триграммам × 0.92)`;
- результат ниже **0.45** считается нулём.

`artist_similarity` — максимум по частям коллаборации и по полной строке.
`album_similarity` — то же, но по очищенным альбомам; пустой альбом даёт **0.0**
(неизвестность не считается совпадением).
`title_similarity` — обычное сходство названий, ловит каверы и ремастеры.

## 4. Жанр

Жанр берётся из плеера, API Яндекса или каталога ЭХО — подробности в
`ARCHETYPES.md`. Если источники молчат, жанр помечается как `unknown`
(«жанр не указан»), а не выдумывается по хешу. Два неизвестных жанра дают
сходство 0.55, а неизвестный с известным — 0.15: неопределённость не считается
совпадением.

Сходство жанров:

| Отношение | Балл |
|---|---|
| тот же жанр | 1.00 |
| родственная пара | 0.72 |
| культурный мост | 0.50 |
| разные миры | 0.15 |

Родственные пары: post-punk↔synthwave, ambient↔electronic, jazz↔trip-hop,
indie↔rock, lo-fi↔trip-hop, classical↔folk, metal↔rock, electronic↔synthwave,
post-punk↔indie.
Мосты: ambient↔classical, jazz↔lo-fi, rock↔folk, post-punk↔electronic,
metal↔ambient, folk↔ambient.

## 5. Акустика

Для каждого жанра есть базовые центры `(BPM, энергия, валентность, лад)`.
Например:

| Жанр | BPM | Энергия | Настроение | Лад |
|---|---|---|---|---|
| post-punk | 128 | 0.56 | 0.36 | A |
| ambient | 78 | 0.28 | 0.50 | B |
| electronic | 124 | 0.76 | 0.50 | A |
| jazz | 96 | 0.45 | 0.66 | B |
| metal | 140 | 0.86 | 0.34 | A |

Хеш трека добавляет отклонение: BPM ±12, энергия/настроение ±0.10,
тональность 1–12 с предпочтением лада жанра.

`Camelot` считается по кольцу 12: та же тональность 1.0, соседняя 0.86,
через одну 0.62, относительная (8A↔8B) 0.72.

`Tempo` складывается по октавам: 120 и 240 — один темп. Допуск 28 % по
логарифму, дальше ноль.

`Energy` и `Mood` — `1 − |разница|`.

## 6. Формула

```
C = 0.36·Artist + 0.20·Album + 0.08·Title + 0.36·Genre
A = 0.30·Camelot + 0.15·Tempo + 0.30·Energy + 0.15·Mood + 0.10·0.84
R = 35 + 65·(0.60·C + 0.40·A)
R = clamp(round(R), 58, 99)
```

- 35 — базовая тишина;
- 65 — вклад совпадения;
- культурный слой весит 60 %, акустический — 40 %;
- `Weight = 0.84` — фиксированный вес из канона.

Если совпали и артист, и название — `R = max(R, 96)`.

## 7. Примеры

| Случай | Резонанс |
|---|---|
| Один и тот же трек | **99** |
| Тот же артист, другой трек и альбом | **81** |
| Разные артисты, тот же жанр (post-punk) | **67** |
| Разные артисты и жанры | **58–61** |

## 8. Объяснение

`resonanceStory` собирается из двух самых сильных причин:

1. «Один и тот же трек — полное совпадение.»
2. «Тот же артист: Кино.» / «Один альбом: Этажи.» / «Похожее название: …»
3. «Один жанр: post-punk.» / «Соседние жанры: …»
4. «Совпали тональности Camelot.»
5. «Темп совпал в пределах октавы.»
6. Иначе — «Тёплый вечерний резонанс…»

Так пользователь видит не только число, но и причину.

## 9. Границы

- Пустой альбом не даёт бонуса, но и не штрафует.
- Призраки (сигнал старше 5 минут) не участвуют в луче и точке Лагранжа.
- Дубли одного трека с одного устройства не создают резонанс: сервер исключает
  собственный `deviceId`.
- Изменение весов — только в `server/resonance.py`; клиент подхватит автоматически.
