# Архетипы ЭХО 2.0

Каждый трек получает свой образ. Он собирается из смысла трека, а не из
случайного числа: одинаковый трек всегда даёт одинаковый архетип, а разные
треки — разные.

## 1. Откуда берётся жанр

Порядок доверия (первое найденное побеждает):

| Приоритет | Источник | Как помечается |
|---|---|---|
| 1 | Плеер: Яндекс Музыка, ВК, SMTC Windows | `player` — «жанр из плеера» |
| 2 | Каталог ЭХО по артисту, названию и альбому | `catalog` — «жанр по каталогу ЭХО» |
| 3 | API Яндекс Музыки (если задан `ECHO_YANDEX_TOKEN`) | `yandex` |
| 4 | iTunes Search API (бесплатно, без ключа), в фоне | `itunes` — «жанр из iTunes» |
| 5 | Жанр не определён | `guess` — «жанр не указан» |

iTunes подключён потому, что он не требует ключа и стабильно доступен в РФ.
Запрос идёт в фоне: трек сразу попадает в эфир с тем, что знает каталог, а
жанр и архетип обновляются через несколько секунд.

Последний вариант не выдумывает жанр. Раньше сервер брал случайный жанр из
хеша, и у викинг-трека появлялся «холодный синти». Теперь при отсутствии
данных честно пишется «жанр не указан», а акустика считается нейтральной.

Технические детали: `genres.py`.

## 2. Мотивы

23 мотива описывают мир трека:

`nordic`, `nightcity`, `space`, `sea`, `forest`, `winter`, `rain`, `road`,
`fire`, `machine`, `dream`, `love`, `club`, `jazz`, `folk`, `war`, `retro`,
`temple`, `home`, `mythic`, `digital`.

У каждого мотива:

- устойчивые основы слов на русском и английском (`драккар`, `drakkar`,
  `панел`, `фонар`, `архангел`, `archangel`…);
- образы в родительном падеже (`драккара`, `северного ветра`, `рунных камней`);
- две атмосферные фразы;
- палитра;
- «тон»: `epic`, `urban`, `quiet`, `cosmic`, `warm`, `ritual`, `road`.

## 3. Выбор мотива

```
score(motif) = Σ по словам трека: вес_поля · (1 + len(слово)/12) + бонус_жанра
вес_поля: title = 3.0, album = 2.0, artist = 1.0
бонус_жанра = 5.0, если жанр из плеера/каталога входит в семьи мотива
```

- Если хоть одно слово трека совпало — побеждает мотив с лучшим счётом.
- Если слов не нашлось — мотив берётся по жанру
  (`post-punk → nightcity`, `ambient → dream`, `nordic folk → nordic`…).
- Если и жанра нет — мягкий мотив по хешу (`nightcity`, `dream`, `road`, `sea`).

Кириллические основы ищутся как часть слова (`панел` → «панельные»), а латинские —
только с начала слова или как точный токен: `bar` не цепляется за «Hubbard»,
зато `munkn` находит «Munknörr». Диакритика складывается:
`Munknörr → munknorr`, `Norðr → nordr`.

## 4. Роль

Роль зависит от тона мотива и акустики трека:

```
quadrant = (valence ≥ 0.5 ? light : dark) + (energy ≥ 0.5 ? high : low)
```

Для каждого тона и квадранта есть свой набор ролей:

| Тон | dark_high | dark_low | light_high | light_low |
|---|---|---|---|---|
| epic | Воевода, Кормчий… | Хранитель, Скальд… | Вожатый, Запевала… | Сказитель, Пастух… |
| urban | Штурман, Гонец… | Сторож, Проводник… | Заводила, Вожатый… | Картограф, Собиратель… |
| quiet | Проводник, Дозорный… | Смотритель, Хранитель… | Вожатый, Запевала… | Созерцатель, Мечтатель… |
| cosmic | Штурман, Ловец… | Смотритель, Хранитель… | Вожатый, Запевала… | Созерцатель, Картограф… |
| warm | Заводила, Ловец… | Хранитель, Свидетель… | Запевала, Заводила… | Мечтатель, Собиратель… |
| ritual | Воевода, Гонец… | Хранитель, Скальд… | Запевала, Вожатый… | Сказитель, Собиратель… |
| road | Гонец, Кормчий… | Проводник, Свидетель… | Вожатый, Заводила… | Странник, Собиратель… |

У `temple` и `jazz` есть собственные роли: Звонарь, Певец, Пианист, Бармен.

## 5. Заголовок

```
personaTitle = роль + образ в родительном падеже
```

- «Скальд драккара»
- «Ловец ночных фонарей»
- «Звонарь сводов собора»
- «Штурман панельных дворов»

Роль выбирается по одному разряду хеша, образ — по другому. Поэтому треки
одного мотива получают разные сочетания, но остаются в своём мире.

## 6. Что ещё меняется

- `moodLabel` теперь всегда подпись жанра («северный фолк»), а не случайное
  «Холодный синти».
- Цвет и число лепестков берутся из палитры мотива.
- Жанр входит в акустику: BPM, энергия, настроение и лад считаются от
  жанрового центра, а не от хеша.

## 7. Примеры

| Трек | Жанр | Архетип |
|---|---|---|
| Danheim — Drums of Drakkar / Vikings | `nordic folk` (каталог) | Запевала рунных камней |
| Молчат Дома — Судно / Этажи | `post-punk` (каталог) | Ловец ночных фонарей |
| Burial — Archangel / Untrue | `electronic` (каталог) | Звонарь сводов собора |
| Brian Eno — An Ending (Ascent) | `ambient` (каталог) | Сказитель сонных облаков |
| Kavinsky — Nightcall / OutRun | `synthwave` (каталог) | Гонец виниловых тресков |
| E-L-R — Seeds / неизвестно | `unknown` | образ без ложного жанра |

## 8. Границы

- Архетип не заменяет жанр: если плеер прислал жанр, он главнее.
- Каталог — это подсказка, а не истина: он расширяется в `genres.py`.
- Сеть не нужна. Яндекс-запрос включается только вручную токеном.
- Изменение словарей не ломает базу: архетип пересчитывается при следующем
  сигнале трека.
